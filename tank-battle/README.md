# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）编写的经典 **坦克大战（Battle City）** 网页小游戏。无需任何依赖，双击 `index.html` 即可游玩。

## ✨ 特性

- 🎮 经典玩法：操控坦克、开火、守卫基地
- 🧱 可破坏的砖墙、不可破坏的钢墙、水域、草丛（可隐藏坦克）
- 🤖 4 种敌人：普通 / 快速 / 火力 / 装甲（需多击）
- 📈 分数、关卡、生命、剩余敌人 HUD
- 🔥 爆炸粒子特效、音效（Web Audio API）
- 📱 支持键盘与触屏操作，响应式布局
- 🗺️ 多个关卡，随关卡递增难度

## 🕹️ 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` 或 `↑` `←` `↓` `→` | 移动坦克 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |
| `回车` / `空格` | 开始 / 重新开始 |

手机端会显示屏幕上的虚拟方向键与开火按钮。

## 🚀 运行

直接用浏览器打开 `index.html`，或启动一个本地服务器：

```bash
# 任意一种方式均可
python -m http.server 8000
# 或
npx serve .
```

然后访问 <http://localhost:8000>。

## 📝 玩法说明

- 守住地图底部中间的 **金色基地（金鹰）**，被敌人击中则游戏结束。
- 消灭当前关卡所有敌人即可过关。
- 每局共 3 条生命，被击中会短暂无敌并重生。
- 草丛可以让坦克隐身，水域坦克无法通过但子弹可以飞过。
